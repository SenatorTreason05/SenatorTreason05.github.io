This is an example post. You can delete it once the site is live.

Jekyll turns Markdown into web pages automatically, so you can write ordinary prose and mathematics without touching HTML. For example,

$$
\sum_{k=1}^{n} k = \frac{n(n+1)}{2}.
$$

To add another post, create a Markdown file in `_posts/` named
`YYYY-MM-DD-title.md` and give it front matter like the block at the top of this file.
